# StructPredictor

StructPredictor is a graph-based AI framework for predicting optimal beam and column section dimensions in reinforced concrete building structures. It uses Graph Transformers and Laplacian positional encodings to perform node-level regression across multiple structural graphs.

## Features

- Graph-based representation of building elements
- Node-level regression (section width & height prediction)
- Laplacian positional encoding
- K-Fold training, validation, and test pipeline
- Excel output and visualization tools
