## راهنمای نصب PyTorch با پشتیبانی GPU (CUDA)

برای اجرای مدل‌ها با استفاده از کارت گرافیک و بهره‌مندی از سرعت بالاتر، نیاز است نسخه‌ی PyTorch مناسب با پشتیبانی CUDA نصب شود. نصب پیش‌فرض PyTorch با دستور `pip install torch`، فقط نسخه CPU را نصب می‌کند.

### مراحل نصب نسخه PyTorch با CUDA:

1. وارد سایت رسمی PyTorch شوید:  
   [https://pytorch.org/get-started/locally/](https://pytorch.org/get-started/locally/)

2. در بخش انتخاب پیکربندی، گزینه‌های زیر را متناسب با سیستم خود انتخاب کنید:  
   - Operating System (سیستم عامل)  
   - Package (معمولاً pip)  
   - Language (مثلاً Python)  
   - Compute Platform (نسخه CUDA کارت گرافیک شما)

3. دستور نصب پیشنهادی سایت را کپی کنید. به عنوان مثال:  
   ```bash
   pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu118
